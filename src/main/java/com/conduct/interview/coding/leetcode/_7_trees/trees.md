# Дерева — шпаргалка

## 1. Дерево

```
            1        ← корінь
           / \
          2   3
         / \
        4   5        ← листки (без дітей)
```

Кожна гілка — теж дерево. Тому задачі на дерева = **рекурсія**: розв'язав для лівого, для правого, поєднав.

---

## 2. BST — бінарне дерево пошуку

**Одне правило: зліва менші, справа більші.**

```
            8
          /   \
         3     10         шукаємо 6:  8 → вліво → 3 → вправо → 6
        / \      \        кожен крок відкидає половину дерева
       1   6      14
```

- Пошук швидкий: **O(log n)**.
- Якщо прочитати зліва направо (inorder) — отримаєш **відсортований** список: `1 3 6 8 10 14`.

---

## 3. Проблема: BST може стати кривим

Вставляємо по порядку `1, 2, 3, 4, 5`:

```
  1
   \
    2
     \
      3         це вже не дерево, а список
       \        пошук: O(n) замість O(log n)
        4
         \
          5
```

**Рішення:** дерево, яке **саме себе вирівнює** після кожної вставки. Найпопулярніше — **Red-Black Tree**.

---

## 4. Red-Black Tree — елементарно

### Ідея в одному реченні

> **Чорні вузли утворюють ідеально рівний каркас, а червоні — це дозволені "вставки" між ними,
> але не більше однієї підряд.**

### Аналогія: будинок з поверхами

- ⚫ **Чорний вузол** — справжній поверх.
- 🔴 **Червоний вузол** — антресоль (напівповерх).

Правила будівництва:
1. У **кожній** колоні будинку **однакова кількість справжніх поверхів** (⚫).
2. Антресоль можна вставити, але **дві антресолі поспіль — заборонено** (🔴🔴 не можна).

Що з цього виходить:

```
  найнижча колона:   ⚫ ⚫ ⚫              = 3 рівні   (тільки поверхи)
  найвища колона:    ⚫ 🔴 ⚫ 🔴 ⚫ 🔴     = 6 рівнів  (після кожного поверху антресоль)
```

**Найвища колона максимум у 2 рази вища за найнижчу.** Будинок не може стати "вежею з одного боку"
→ дерево не може стати списком → пошук **завжди O(log n)**.

Ось і весь сенс кольорів: це просто **позначка, за якою дерево дешево перевіряє, чи воно ще рівне**.

### Як виглядає

```
              ⚫8
            /     \
         🔴4       🔴12
         /  \      /   \
       ⚫2  ⚫6   ⚫10  ⚫14

   кожен шлях вниз проходить рівно 2 чорних: 8→4→2, 8→4→6, 8→12→10, 8→12→14
   червоні ніде не стоять підряд
```

### Що відбувається при вставці

1. Вставляємо як у звичайне BST, новий вузол фарбуємо в 🔴.
2. Якщо вийшло 🔴🔴 підряд — дерево **ремонтує себе**: перефарбовує вузли або робить **поворот**:

```
  1                         2
   \                       / \
    2       поворот  →    1   3        порядок той самий (1 < 2 < 3),
     \                                 але дерево стало рівним
      3
```

Деталі поворотів на співбесіді майже ніколи не питають. Достатньо знати **навіщо** вони.

### Де в Java

- `TreeMap`, `TreeSet` — це red-black tree.
- `HashMap` — якщо в одному бакеті ≥ 8 елементів, список у ньому стає red-black tree.

### AVL — друге самобалансоване дерево

**AVL** — за прізвищами авторів: **A**delson-**V**elsky і **L**andis (1962). Перше в історії самобалансоване дерево.

Теж BST, що вирівнює себе, але **суворіше**: висоти лівого і правого піддерева різняться максимум на 1.
Пошук трохи швидший, вставка повільніша (більше поворотів). У бібліотеках зазвичай обирають Red-Black.

## 5. Інші популярні дерева

**Heap** — найменший елемент завжди нагорі. `PriorityQueue` у Java.
```
        1
       / \          батько ≤ дітей
      3   2         зберігається в масиві: [1, 3, 2, 7]
     /
    7
```

**Trie** — дерево з букв, для пошуку за префіксом (автодоповнення).
```
       c
       |
       a            слова: cat, car
      / \
     t   r
```

**B-Tree** — багато ключів в одному вузлі, дерево дуже низьке. Так зроблені **індекси в БД**.
```
          [10 | 20]
         /    |    \
     [1 5]  [15]  [25 30]
```

---

## 6. Обходи

```
            1
           / \
          2   3
         / \
        4   5
```

| Обхід | Порядок | Результат |
|---|---|---|
| **Preorder** | **вузол** → ліве → праве | `1 2 4 5 3` |
| **Inorder** | ліве → **вузол** → праве | `4 2 5 1 3` ← для BST відсортовано |
| **Postorder** | ліве → праве → **вузол** | `4 5 2 3 1` |
| **Level order** | рівень за рівнем | `[1] [2,3] [4,5]` |

pre / in / post — де стоїть **вузол**. Перші три — DFS (рекурсія), level order — BFS (черга).

Код: `_1_traversal/`, задачі: `_2_dfs_problems/`.

## 7. Запам'ятати

| Дерево | Одним рядком | У Java / в житті |
|---|---|---|
| **BST** | зліва менші, справа більші | основа для пошуку |
| **Red-Black** | BST, що сам себе вирівнює; пошук завжди O(log n) | `TreeMap`, `TreeSet`, `HashMap` |
| **AVL** | теж вирівнюється, але суворіше | рідше |
| **Heap** | мінімум нагорі | `PriorityQueue` |
| **Trie** | дерево з букв | автодоповнення |
| **B-Tree** | низьке й широке | індекси БД |

**Red-Black за 10 секунд:** чорні — рівний каркас, червоні — вставки не більше однієї підряд →
найдовший шлях ≤ 2× найкоротшого → дерево не стане списком.
